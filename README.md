# MiniShop Lab

Учебное веб-приложение интернет-магазина для практики анализа безопасности с помощью Reverse Engineer Anything (REA).

## Возможности

- Просмотр каталога товаров.
- Поиск товаров.
- Демонстрация авторизации и управления сессией.
- Корзина.
- Safe mode и учебный Training mode.

## Запуск

Требуется установленный Node.js.

```bash
npm install
npm start
```

После запуска откройте http://localhost:3000.

## Материалы исследования

- `REA-REPORT.md` — отчёт по исследованию.
- `artifacts/` — результаты проверок и материалы REA.
- `server.js` — серверная часть приложения.
- `public/` — интерфейс приложения.

Проект предназначен для учебного использования в локальной среде.
